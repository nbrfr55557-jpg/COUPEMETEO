# Coupe Météo Hélico

Page web autonome de préparation météo pour hélicoptère, sur un trajet ou un point :
base des nuages (ft sol), visibilité, relief, vent par tranches et givrage, avec repérage du point le plus défavorable.

- Données : [Open-Meteo](https://open-meteo.com/) (CC BY 4.0) — Météo-France AROME/ARPEGE, DMI Harmonie, DWD ICON-D2, ECMWF IFS.
- Relief : Copernicus GLO-90 via l'API élévation d'Open-Meteo.
- Fond de carte : OpenTopoMap / OpenStreetMap.

Aide à la décision uniquement : ne remplace pas les produits météo officiels. Usage non commercial.
